## Who’s Next?

A platform to discover emerging talents.

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Other useful commands:

```bash
npm run lint
npm run build
```

If you run into `Can't resolve 'tailwindcss' in '/Users/.../GitHub'`, your command is likely being executed from the parent folder. Make sure you’re running commands from `wn-web/`.

## Contributing

PRs are welcome.

Suggested workflow:

- Open an issue describing the bug/feature.
- Create a branch and submit a PR.
- Run `npm run lint` and `npm run build` before pushing.
